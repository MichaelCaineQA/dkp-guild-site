# Установщик ДКП для Ubuntu

Поддерживаются Ubuntu 22.04 и 24.04, архитектуры amd64 и arm64. Нужны
Python 3, openssl, tar, systemd и доступ администратора сервера. Порты TCP
80 и 443 должны быть свободны, DNS домена должен указывать на этот VPS.
TeamSpeak управляется отдельно и установщиком не изменяется.

1. Скачайте архив релиза и файл `.sha256` с одной страницы GitHub Releases.
   Проверьте `sha256sum -c dkp-guild-site-<версия>.tar.gz.sha256` и
   распакуйте `tar -xzf dkp-guild-site-<версия>.tar.gz`.
2. В каталоге релиза выполните `sudo ./dkp start`. Мастер спросит домен,
   название гильдии, пароль администратора, необязательный Discord и параметры
   ежедневной копии. Если Docker отсутствует, установка пакетов apt потребует
   отдельного подтверждения. Для Discord добавьте показанный callback в
   настройки Discord-приложения.
3. Для SSH-хранилища заранее подтвердите ключ сервера в `known_hosts` **того
   пользователя, от которого запускается dkp** (при `sudo` — root), создайте
   каталог на другом сервере и настройте доступ по ключу без интерактивного
   пароля. Проверка записи выполняется мастером. Локальный режим оставляет
   копию на самом VPS и не защищает от потери этого сервера.
4. Сохраните файл ключа восстановления, созданный мастером, отдельно от VPS
   и резервного хранилища. Для восстановления на другом VPS потребуется этот
   файл и SSH-ключ. Потеря ключа делает зашифрованные копии недоступными.
5. Войдите как Админ. Если Discord настроен, будущий Глава входит через
   Discord и заполняет анкету; Админ её одобряет и назначает Главу через смену
   ранга в разделе «Состав». Установщик не назначает Главу автоматически.

`./dkp help` показывает команды; обычно все операции запускаются через sudo.
`backup now` создаёт копию немедленно, `backup list` перечисляет копии,
`backup restore <id>` требует подтверждения домена и создаёт предварительную
копию текущих данных. `backup setup` меняет хранилище и расписание.
`update [v1.2.3]` скачивает релиз, проверяет суммы и делает копию до миграции.
При ошибке миграции API остаётся остановленным: используйте `status`, `logs`
и восстановление копии; смена образа сама по себе не откатывает БД.

Настройки и рабочие копии находятся в `/var/lib/dkp-guild` с ограниченными
правами, файлы БД и скриншоты — в томах Docker проекта `dkp-guild`. Расписание
использует только `dkp-guild-backup.service` и `dkp-guild-backup.timer`.
Команды управления ограничены этим проектом Compose.

Для переноса разверните ту же версию релиза на отдельном VPS, перенесите ключ
восстановления безопасным способом, настройте доступ к прежнему SSH-хранилищу
через `backup setup` и выполните `backup restore <id>`. После восстановления
проверьте сайт, журнал и скриншоты. Повторяйте контрольное восстановление на
отдельном окружении не реже раза в месяц. Секреты не помещайте в чат или issue.

Для скачивания приватных GitHub Releases и образов GHCR необходима отдельная
авторизация GitHub и Docker; автоматическое обновление поддерживает публичные
release assets. Для публичного использования владелец репозитория должен
проверить видимость обоих пакетов GHCR и release assets.
