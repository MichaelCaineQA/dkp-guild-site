# DESIGN.md — спецификация дизайна сайта

Документ для фронтенд-трека (issues #23 → #24 → #25): что где лежит, какие
роли у цветов, как устроены компоненты и как меняется дизайн. Соглашения
фиксируются здесь; палитра — в `app/globals.css`.

## Где что лежит

| Что | Где | Комментарий |
|---|---|---|
| Палитра + шрифт | `app/globals.css` | Только значения: `--surface`, `--accent`, …; светлая и тёмная тема |
| Вёрстка и стили | `components/ui/` | Примитивы — единственное место с Tailwind-классами |
| Экраны | `app/**/page.tsx` | Данные, права, обработчики; стилей не пишут |
| Витрина | `/design` | Палитра и все компоненты на живых примерах |

## Палитра: семантические роли

Имена — о роли, не о значении. Менять можно значения, роли фиксированы:

| Роль | Назначение |
|---|---|
| `bg-page` | Фон страницы |
| `surface` | Карточки, панели, шапка |
| `surface-muted` | Приглушённые зоны: строки таблиц, чипы |
| `text-primary` / `text-secondary` / `text-disabled` | Основной / пояснительный / недоступный текст |
| `border` / `border-strong` | Линии и рамки / выделенные рамки |
| `accent` (+ `hover`, `contrast`, `soft`) | Ссылки, активная навигация, основные кнопки |
| `success` / `danger` / `warning` (+ `soft`) | Успех / ошибка / предупреждение |

В компонентах используются как Tailwind-цвета: `bg-surface`,
`text-secondary`, `border-line`, `bg-accent-soft` и т.п. — они следуют за
палитрой и темой автоматически.

Тёмная тема — те же роли, другие значения; включается по системной
настройке браузера (`prefers-color-scheme`).

## Типографика и метрики

Шрифт — системный стек (`--font-sans`); при смене на фирменный меняется
одна переменная.

| Уровень | Класс | Использование |
|---|---|---|
| Заголовок страницы | `text-2xl font-semibold` | H1, один на экран |
| Заголовок карточки | `text-lg font-semibold` / `text-xl` | H2 внутри контента |
| Основной текст | `text-sm` | Тело карточек, таблицы |
| Пометки | `text-xs` | Бейджи, подписи |
| Пояснения | `text-secondary` | Подзаголовки, счётчики, «—» в пустых ячейках |

Радиусы: карточки `rounded-xl`, контролы `rounded-lg`, бейджи `rounded-full`.
Тени: `shadow-sm` на карточках. Отступы — кратны шагу Tailwind (0.25rem).

## Компоненты (`components/ui`)

| Примитив | Назначение |
|---|---|
| `Page` | Обёртка экрана: центр, ширина (narrow/regular/wide) |
| `PageHeader` | H1 + подзаголовок |
| `Card` | Контейнер контента |
| `SectionTitle` | H2 внутри карточки |
| `Notice` | Инфо/успех/ошибка — пояснения и пустые состояния |
| `ErrorText`, `Muted` | Ошибка у контрола / приглушённый текст |
| `Button` | primary (основное действие) / secondary / danger |
| `Input`, `Select`, `Field` | Поля ввода |
| `Badge` | Роль в бою, ранг, статус (тон = семантика) |
| `Table` (+ `Th`/`Td`/`Row`) | Данные; `Row` — кликабельная строка |

Новые визуальные элементы добавляются сюда, а не стилизуются на страницах.

## Процесс редизайна

1. **Варианты** (#23): 2–3 направления — ветки `design/variant-*` со своими
   значениями палитры в `globals.css`. Смотреть на `/design` и живой странице.
2. **Согласование** (#24): глава смотрит живую витрину (локально или staging) —
   не скриншоты в GitHub. Выбор фиксируется комментарием в issue.
3. **Перевёрстка** (#25): согласованная палитра → `globals.css`; структура
   блоков → только `components/ui`. Страницы не переписываются.

## Требования ко всем вариантам

- Обе темы: значения для светлой и тёмной обязательны.
- Мобильная версия: телефон — полноценный сценарий (отметиться кодом).
- Только русский язык интерфейса.
- Контраст текста достаточен для чтения (текст `secondary` — не серый на сером).
