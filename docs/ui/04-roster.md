## Подвкладка «КП»

- ✅ Изначально — **пустой список + фильтр по КП**; чтобы отобразился список,
  нужно выбрать КП из существующих.
- ✅ Для Главы и Админа — кнопка **«Создать КП»**.

### Форма создания КП

- ✅ Ввод **названия КП** (поле названия обязательно — решено [В], вброс 5).
- ✅ Строка поиска **по всем пакам** (поиск по названию) + пустой список под
  ней.
- ✅ Клик по найденному паку → пак добавляется в список.
- ✅ Под списком кнопка «Принять» → выбранные паки **переносятся из других
  КП в этот**; у игроков из перечисленных паков КП тоже меняется.
- ✅ Можно создавать **пустой КП** (без паков) — решено [В], 2026-11-06.

### Выбранный КП

- ✅ Список игроков этой КП, **сортировка по пакам по алфавиту** (❓ поля
  строки — предположительно как в «Участниках»).
- ✅ У игрока, отмеченного как **лидер КП**, — **золотая корона** рядом с
  ником; **лидер пака** — **серебряная корона** (решено [В], 2026-11-06).
- ✅ Если в фильтре выбрана КП, появляется кнопка **«Поменять лидера»**
  (лидера КП). Доступна **только Главе гильдии и Админу**.
  - Действие: модалка со списком игроков КП; выбор игрока → он становится
    лидером КП. ❓ подтверждение; AuditLog-запись.

## Подвкладка «Пак»

- ✅ Изначально — **пустой список + фильтр по Пакам**; чтобы отобразился
  список, нужно выбрать Пак из существующих.
- ✅ Кнопка **«Создать Пак»** — для Главы, Админа и **лидера КП, к которому
  относится пак** (❓ как определяется «КП Пака» до создания — какой КП
  подставляется в форму? видимо, выбор КП на форме).

### Форма создания Пака

- ✅ Ввод **названия пака** (поле названия обязательно — решено [В], вброс 5).
- ✅ Строка поиска **по всем игрокам в КП Пака** (поиск по нику) + пустой
  список под ней.
- ✅ Клик по найденному игроку → игрок добавляется в список.
- ✅ Под списком кнопка «Принять» → игроки **переносятся из других паков в
  этот**.
- ✅ **Ограничение: добавлять можно только игроков из одного и того же КП!**
- ✅ Можно создавать **пустой пак** (без игроков) — решено [В], 2026-11-06.

### Выбранный Пак

- ✅ Список игроков этого пака, **сортировка по никам по алфавиту**.
- ✅ У игрока, отмеченного как **лидер КП**, — **золотая корона** рядом с
  ником; **лидер пака** — **серебряная корона** (решено [В], 2026-11-06).
- ✅ Если в фильтре выбран Пак, появляется кнопка **«Поменять лидера»**
  (лидера пака — отдельная роль, хранится полем на сущности Пак, см. заметки).
  - Доступна **Главе гильдии, Админу и лидеру КП**.
  - Действие: модалка со списком игроков пака; выбор игрока → он становится
    лидером пака.

## Заметки для реализации

- Все действия здесь — ручные: **каждое обязано писать AuditLog** (правило 4
  AGENTS.md): перемещение игрока, создание КП/пака, перенос паков/игроков,
  смена лидеров, приём заявки.
- **Лидерство — отдельные поля в БД** (решено [В], вброс 5): у сущности
  **Пак** — поле-ссылка (id пользователя) на лидера пака; у сущности **КП** —
  аналогичное поле на лидера КП. Т.е. «лидер пака» и «лидер КП» —
  независимые роли, каждая хранится на своей сущности. Значки: лидер КП —
  **золотая корона**, лидер пака — **серебряная корона** (решено [В],
  2026-11-06); «глава пака» на дашборде = лидер пака (серебряная корона).
- **Иерархия и правила переносов** (обновлено [В], 2026-11-06): паки
  переносятся между КП; игроки переносятся **и между паками, и между КП**
  (оба поля модалки «Переместить» редактируемые, список паков фильтруется по
  выбранному КП). При создании пака по-прежнему — только игроки одного КП.
- Инварианты: игрок принадлежит ровно одному паку; пак принадлежит ровно
  одному КП; при переносе пака КП всех его игроков обновляется.
- При переносе лидера (игрока из пака / пака из КП) **лидерство снимается**
  (не передаётся автоматически).
- Хранить **дату добавления игрока в пак** — нужна для сортировки «Моя
  команда» на дашборде (fallback: дата регистрации).
