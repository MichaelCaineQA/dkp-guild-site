# UI-справочник сайта гильдии Sun Eclipse

## Назначение

Справочник интерфейса: какие экраны есть, что на них расположено, какие
действия доступны и кому. **Это не документ требований**: игровые правила и
решения гильдии фиксируются только в `docs/PLAN.md`, здесь — ссылки на него.
Задачи и статус фич ведём в GitHub Issues.

## Конвенции

### Ранги и назначения

Ранги по модели PLAN.md (раздел 2.6), в интерфейсе поле называется **«Ранг»**
(решено [В], 2026-11-06):

- **Глава** — глава гильдии
- **Админ** — администратор сайта
- **Офицер** — офицер гильдии; ранг подтверждён PLAN.md, раздел 2.6.
  ✅ Права из ревизии (ответ 32) перенесены в PLAN.md, раздел 2.6:
  управление расписанием и просмотр полного аудита. Коды и итоги — только
  при назначении РЛ соответствующего ивента; управление составом/КП/паками —
  по ограничениям Главы/Админа и назначений лидеров, описанным в экранах.
- **Рядовой** — обычный участник гильдии

Назначения и обозначения:

- **РЛ** — рейд-лидер ивента; **не ранг**, а ответственный за событие
  (поле id участника у сущности Event); расширенные настройки — только
  в карточке назначенного ему ивента
- **Лидер КП / лидер пака** — поля (id участника) на сущностях КП/Пак
- **Игрок** — одобренный участник

Ранг отделён от **боевой роли** («ДД», «Хил», «Танк») и назначений лидера
КП/пака или РЛ ивента. Ранг показывается текстовым бейджем рядом с ником;
лидерство КП/пака — золотой/серебряной короной соответственно.

### Итоговая матрица управляющих действий

Ревизия [В], ответы 14, 19, 26–27, 32. Назначения РЛ/лидеров дают права
только в пределах своих ивентов/КП/паков; ранг Офицера сам по себе их не даёт.

| Действие | Кто может |
|---|---|
| Создать ивент, назначить РЛ | Глава, Админ, Офицер |
| Редактировать/отменить запланированный или идущий ивент | Глава, Админ, Офицер; назначенный РЛ — свой ивент |
| Удалить запланированный ивент | Глава, Админ, Офицер; назначенный РЛ — свой ивент |
| Видеть коды и проводить ивент | Глава, Админ, назначенный РЛ, создатель-Офицер |
| Корректировать итоги завершённого ивента | Глава, Админ, назначенный РЛ, создатель-Офицер |
| Менять ранг, принимать заявки, перемещать игроков, создавать КП, менять лидера КП | Глава, Админ |
| Создавать пак и менять его лидера | Глава, Админ, лидер соответствующей КП |
| Читать полный журнал действий | Глава, Админ, Офицер |
| Менять настройки системы | Глава, Админ |

В отменённом ивенте доступен только просмотр; в завершённом обычное
редактирование закрыто. Видимость GS и скриншотов задаётся отдельно:
[07-profile.md](07-profile.md).
