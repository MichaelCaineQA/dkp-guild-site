# UI-справочник сайта гильдии Sun Eclipse

## Назначение

Справочник интерфейса: какие экраны есть, что на них расположено, какие
действия доступны и кому. **Это не документ требований**: игровые правила и
решения гильдии фиксируются только в `docs/PLAN.md`, здесь — ссылки на него.
Задачи и статус фич ведём в GitHub Issues.

## Конвенции

### Роли

Роли, встречающиеся в описаниях (соответствие ролям модели PLAN — ❓ сверить):

- **Глава** — глава гильдии
- **Админ** — администратор сайта
- **Офицер** — офицер гильдии (упомянут во вбросе 10: право создавать ивенты;
  ❓ сверить с ролями модели PLAN и добавить в матрицы прав других экранов,
  если роль подтверждена)
- **РЛ** — рейд-лидер ивента; **не роль сайта**, а ответственный за событие
  (поле id пользователя у сущности Event); расширенные настройки — только
  в карточке назначенного ему ивента
- **Лидер КП / лидер пака** — поля (id пользователя) на сущностях КП/Пак
- **Игрок** — одобренный участник

### Пометки

- ✅ — зафиксировано (решение владельца/заказчиков)
- ❓ — открытый вопрос
- 💡 — идея, не решение
- Источник: **[В]** владелец, **[З]** заказчики

### Шаблон файла экрана

1. Роут и доступ
2. Макет
3. Элементы
4. Действия
5. Состояния (пусто / загрузка / ошибки / нет прав / мобайл)
6. Открытые вопросы
7. Источник
