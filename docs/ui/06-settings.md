## Текущий набор настроек

Сверено с `packages/shared/src/settings.ts` и Prisma-схемой. Источник
допустимых значений и дефолтов — `SETTINGS_REGISTRY` / `SETTING_DEFAULTS`;
при изменении реестра интерфейс должен отражать его актуальный состав.

В модели **Setting** сейчас 13 ключей:

| Раздел | Ключи |
|---|---|
| Чек-ин | `checkin.generateBeforeStartSec` — генерация до старта; `checkin.windowSec` — окно выбора; `checkin.attempts` — число попыток; `checkin.startSharePct` / `checkin.endSharePct` — доли платы |
| Отсутствия | `absence.deadlineBeforeStartSec` — дедлайн подачи до старта |
| Аукцион | `auction.step` — минимальный шаг; `auction.liveDurationSec` — длительность живой раздачи; `auction.longDurationDays` — длительность длинного лота; `auction.antiSnipeLiveSec` / `auction.antiSnipeLongSec` — анти-снайп; `auction.foreignClassMarkupPct` — наценка чужому классу; `auction.noBidTimeoutSec` — тайм-аут без ставок |

Игровой цикл редактируется на том же экране, но хранится в **Guild**:
`gameTimeAnchor`, `gameTimeDayMinutes`, `gameTimeNightMinutes` — якорь,
длительности дня и ночи. API: `/settings` и `/settings/game-time`.

## Группировка и аудит

- ✅ Настройки **группируются по разделам** (ДКП / чек-ин / аукцион / общие —
  состав групп уточнить при реализации; решено [В], 2026-11-06).
- ✅ Изменение настройки **пишется в AuditLog** (решено [В], 2026-11-06).

## Проверка и сохранение

- ✅ Неверное значение сопровождается **пояснением возле поля**; ограничения
  соответствуют общей схеме/реестру настроек (решено [В], ревизия, ответ 29).
- ✅ При ошибке сохранения введённые значения **сохраняются в форме**,
  показывается сообщение об ошибке. Пользователь может исправить ввод
  или повторить сохранение.

## Сброс к дефолтам

- ✅ В каждом разделе — кнопка **«Сбросить к дефолтам»** с подтверждением
  (решено [В], ревизия, ответ 30).
- После подтверждения **только поля этого раздела в форме** заполняются
  значениями по умолчанию. Серверные настройки меняются лишь после
  **«Сохранить»**; отмена подтверждения не меняет форму.
- Для ключей `Setting` источник значений — `SETTING_DEFAULTS`. Применение
  сохранённых изменений фиксируется в AuditLog; заполнение формы само по
  себе серверные настройки не меняет.
- Сброс игрового цикла восстанавливает дефолтные длительности дня/ночи
  из схемы `Guild`. Якорь сохраняет известную серверную привязку: для него
  нет универсального момента времени, который подошёл бы любому серверу.
