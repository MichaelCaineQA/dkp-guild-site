# Дашборд

Статус: черновик · Источник: [В] первый вброс 2026-11-06

## Роут и доступ

- Точка входа по умолчанию для одобренных игроков после логина.
- Доступ: ✅ все авторизованные и одобренные игроки. ❓ отличается ли вид для
  РЛ/Главы/Админа.

## Макет

✅ Четыре виджета **одинакового размера**, сетка 2×2, занимают всю полезную
область страницы:

```
┌──────────────────────┬──────────────────────┐
│ События дня          │ Моя команда          │
├──────────────────────┼──────────────────────┤
│ Мой аукцион          │ События (лог)        │
└──────────────────────┴──────────────────────┘
```

❓ Мобильная версия: одна колонка? порядок виджетов? ❓ равные размеры — при
переполнении контента прокрутка внутри виджета?

## Виджет 1. «События дня» (верхний левый)

Список событий текущего дня. Каждая запись: **время, название, тип события**.

- ✅ Прошедшие события визуально затемняются.
- ✅ Клик на событие → **КАРТОЧКА СОБЫТИЯ** — модалка, та же, что в
  календаре расписания (решено [В], 2026-11-06; см. [03-schedule.md](03-schedule.md)).
- ✅ День — **по Москве (GMT+3)**, не по таймзоне игрока (решено [В],
  2026-11-06; исключение из правила 5 AGENTS.md — зафиксировать в PLAN.md
  при переносе в репозиторий).
- ✅ Показываются **ближайшие 5** событий дня; старые убираются из выборки.
  Прошедшие из показанных затемняются.
- ✅ Пустое состояние: **«Сегодня отдыхаем!»**

## Виджет 2. «Моя команда» (верхний правый)

Заголовок: «Моя команда: {имя команды}» — состав **пака** пользователя.

Каждая запись игрока: **аватар, ник, значок короны (если глава пака), класс,
роль, GS**.

- ✅ Глава пака всегда первый в списке.
- ✅ Клик на запись → **ПРОФИЛЬ ИГРОКА** (❓ тот же экран, что «Профиль
  персонажа» из шапки?).
- ✅ После лидера игроки сортируются по **дате добавления в пак** (fallback —
  дата регистрации) — решено [В], 2026-11-06. Заметка: хранить дату
  добавления в пак.
- ✅ Игрок без пака: заглушка **«Здесь появится информация о твоём паке
  после того, как тебя распределят»**.

## Виджет 3. «Мой аукцион» (нижний левый)

Предмет, на который пользователь делал ставку, из **аукциона с самым ранним
временем окончания** (среди ставок пользователя).

Отображается: **картинка предмета, название, время окончания аукциона, текущая
ставка, кто её сделал**.

- ✅ Кнопка «Открыть аукцион» → **АУКЦИОН** (экран не описан).
- ✅ Пустое состояние — заглушка (текст выбрать при реализации).
- ❓ обновляется ли текущая ставка динамически (перелив ставок) или только при
  загрузке страницы.

## Виджет 4. «События» (нижний правый)

✅ 10 последних записей из **журнала действий (AuditLog)** — формат записей
см. [05-audit-log.md](05-audit-log.md).

- ✅ Кнопка «Перейти в лог действий» → **ЛОГ ДЕЙСТВИЙ**.
- ✅ Клик по записи ничего не открывает — полный лог только по кнопке
  (решено [В], 2026-11-06).
- 💡 Название «События» пересекается с виджетом «События дня» — возможно,
  переименовать («Журнал», «Последние действия»)? Решение за владельцем.
