# Экран приветствия (+ первый вход)

Статус: вопросы ревизии согласованы (2026-11-06) · Источник: [В] первый вброс 2026-11-06

## Роут и доступ

- Роут: `/` для неавторизованных пользователей; после одобрения и входа
  тот же адрес открывает дашборд (текущий маршрут `apps/web/app/page.tsx`).
- Единственный экран для гостей: **без шапки и боковой шторки**.

## Макет

Всё по центру страницы:

```
Приветствуем в Sun Eclipse!
Чтобы продолжить, авторизуйтесь

[ Связать с Discord ]
[ Вход для Админа ]
```

## Элементы и действия

| Элемент | Действие | Что происходит |
|---|---|---|
| Кнопка «Связать с Discord» | клик | ✅ Переход на OAuth-авторизацию Discord |
| Кнопка «Вход для Админа» | клик | ✅ Открывается модалка с полями логина и пароля (решено [В], ревизия, ответ 7). Восстановления пароля **нет** — пароль хранится в секретах GitHub-проекта |
| Форма логина/пароля | отправка | ✅ Вход как Админ; после входа — **Дашборд**, как у всех (решено [В], 2026-11-06) |

### Ошибки входа администратора

При отложенной настройке Discord (установка по #75) ссылка авторизации скрыта,
показано «Вход через Discord пока не настроен», вход администратора доступен.
Доступность загружается с API; ошибка проверки показана отдельно и не блокирует
форму администратора.

- ✅ Неверные данные: под формой сообщение **«Неверный логин или пароль»**;
  введённый логин сохраняется (решено [В], ревизия, ответ 8).
- ✅ Лимит — **5 попыток входа за 15 минут** с одного IP-адреса. При
  превышении API возвращает HTTP 429; форма сообщает о временном ограничении
  и сохраняет логин. Лимит относится ко всем запросам входа, включая успешные.

## Поток первого входа через Discord

1. Пользователь проходит Discord-авторизацию.
2. Если вход **первый** → экран первого заполнения профиля:
   - ник в игре
   - класс
   - количество ГС
   - прикрепить скриншот профиля персонажа, на котором видны **ник и GS**
     (PLAN.md, раздел 2.5)
   - ✅ все поля **обязательные** (решено [В], 2026-11-06)
   - ✅ GS — **положительное целое число**: 0, отрицательные и дробные
     значения не допускаются; дополнительных игровых порогов минимума и
     максимума нет (решено [В], ревизия, ответ 9)
   - ✅ Скриншот — **PNG, JPG/JPEG или WebP, до 10 МБ включительно**
     (решено [В], ревизия, ответ 10). Те же ограничения применяются при
     обновлении GS и скриншотов в профиле.
3. После отправки анкеты **доступа к сайту нет** — экран ожидания
   подтверждения от Главы гильдии или Админа (одобрение — в «Заявках»,
   см. [04-roster.md](04-roster.md)).
   - ✅ Экран ожидания — **без шапки и бокового меню** (решено [В],
     2026-11-06).
   - ✅ На экране ожидания можно **выйти из аккаунта** и **отредактировать
     анкету** до одобрения (решено [В], 2026-11-06).
   - ✅ Отклонения заявок нет — ожидание бессрочное (см. 04-roster.md).
4. Если пользователь уже входил ранее (одобрен) → переход на **Дашборд**.
