# Экран приветствия (+ первый вход)

Статус: черновик · Источник: [В] первый вброс 2026-11-06

## Роут и доступ

- Доступ: неавторизованные пользователи. ❓ точный роут (корень `/` для гостей?)
- Единственный экран для гостей: **без шапки и боковой шторки**.

## Макет

Всё по центру страницы:

```
Приветствуем в Sun Eclipse!
Чтобы продолжить, авторизуйтесь

[ Связать с Discord ]
[ Вход для Админа ]
```

## Элементы и действия

| Элемент | Действие | Что происходит |
|---|---|---|
| Кнопка «Связать с Discord» | клик | ✅ Переход на OAuth-авторизацию Discord |
| Кнопка «Вход для Админа» | клик | ✅ Показывается поле для ввода логина и пароля админа. ❓ вид: модалка или разворот на месте; поведение при неверном вводе; восстановление пароля |
| Форма логина/пароля | отправка | ✅ Вход как Админ; после входа — **ДАШБОРД**, как у всех (решено [В], 2026-11-06) |

## Поток первого входа через Discord

1. Пользователь проходит Discord-авторизацию.
2. Если вход **первый** → экран первого заполнения профиля:
   - ник в игре
   - класс
   - количество ГС
   - прикрепить скриншот с подтверждением (❓ подтверждение чего именно — ГС?)
   - ❓ какие поля обязательны, валидация ГС (диапазон?), форматы/размер скриншота
3. После отправки анкеты **доступа к сайту нет** — экран ожидания
   подтверждения от Главы гильдии или Админа (одобрение — в «Заявках»,
   см. [04-roster.md](04-roster.md)).
   - ✅ На экране ожидания можно **выйти из аккаунта** и **отредактировать
     анкету** до одобрения (решено [В], 2026-11-06).
   - ✅ Отклонения заявок нет — ожидание бессрочное (см. 04-roster.md).
4. Если пользователь уже входил ранее (одобрен) → переход на **ДАШБОРД**.
