# Общие элементы: шапка (хедер) и боковая шторка

Статус: вопросы ревизии согласованы (2026-11-06) · Источник: [В] первый вброс 2026-11-06

## Где показываются

На всех экранах, **кроме**:

- Экрана приветствия (см. [01-welcome.md](01-welcome.md))
- Экрана первого заполнения профиля (см. [01-welcome.md](01-welcome.md))
- ✅ Экрана ожидания одобрения — без шапки и боковой шторки
  (решено [В], 2026-11-06; см. [01-welcome.md](01-welcome.md))

## Шапка (верхняя полоса на всю ширину)

Элементы слева направо:

| Элемент | Расположение | Вид и поведение |
|---|---|---|
| Герб гильдии + название гильдии | левый угол | ✅ Логоблок; клик → **Дашборд** (решено [В], 2026-11-06) |
| Игровое время | центр | ✅ Иконка текущей фазы (день/ночь) + сколько осталось до смены фазы. Точное время смены — в подсказке при наведении, на телефоне — по нажатию (решено [В], 2026-11-06). Расчёт — `getGamePhase` из `packages/shared`, якорь цикла день/ночь — настройка гильдии (см. AGENTS.md, правило 5) |
| Количество очков ДКП | правый угол | ✅ Баланс игрока (сумма записей журнала) — просто цифра, не кликабельна (решено [В], 2026-11-06) |
| Аватар игрока | правый угол | ✅ Иконка, выбранная игроком из нескольких готовых сгенерированных иконок. Один и тот же выбранный аватар используется в шапке и списках игроков (решено [В], 2026-11-06) |
| Ник игрока | правый угол | ✅ Клик по нику или аватару → **ПРОФИЛЬ ПЕРСОНАЖА** |
| Ранг | правый угол | ✅ Текстовый бейдж рядом с ником: «Глава», «Админ», «Офицер», «Рядовой». Лидерство КП/пака обозначается отдельно: золотая/серебряная корона (решено [В], 2026-11-06) |
| Кнопка «Выход» | правый угол | ✅ С подтверждением; после выхода — экран приветствия (решено [В], 2026-11-06) |

## Боковая шторка (навигация по разделам)

- Расположена в левой части экрана.
- ✅ **Свёрнута по умолчанию**: видны только иконки пунктов.
- ✅ В верхней части шторки — кнопка разворачивания (иконка «три
  горизонтальные линии»).
- ✅ Вертикальный список разделов; клик по пункту — переход на страницу.
- ✅ Названия разделов пишутся обычным регистром: «Расписание»,
  «Состав гильдии», «Настройки» (решено [В], 2026-11-06).

| Пункт | Кому виден | Цель перехода |
|---|---|---|
| Дашборд | ✅ все | [02-dashboard.md](02-dashboard.md) |
| Расписание | ✅ все авторизованные и одобренные игроки | [03-schedule.md](03-schedule.md) |
| Состав гильдии | ✅ все авторизованные и одобренные игроки | [04-roster.md](04-roster.md) |
| Аукцион | ✅ все авторизованные и одобренные игроки (PLAN.md 2.4/2.6) | ⏸ описание к этапу 2 |
| Лог действий | ✅ только Офицер, Глава и Админ | [05-audit-log.md](05-audit-log.md) |
| Настройки | ✅ только Глава и Админ | [06-settings.md](06-settings.md) |

- ✅ Пункты, недоступные по правам, **скрываются целиком** (не блокируются)
  (решено [В], 2026-11-06).
- ✅ Это общее правило всех экранов: кнопки действий, недоступных по правам,
  тоже **скрываются** (решено [В], 2026-11-06). Оно не относится к временной
  недоступности действия, например во время отправки формы.
- ✅ Мобильная версия: шторка выдвигается **поверх хедера** — удобно
  пользоваться только ей (решено [В], 2026-11-06).
- ✅ Активный раздел **подсвечивается** в шторке (решено [В], 2026-11-06).
- ✅ Состояние шторки (свёрнута/развёрнута) **запоминается** между страницами
  и сессиями (решено [В], 2026-11-06).
