# Общие элементы: шапка (хедер) и боковая шторка

Статус: черновик · Источник: [В] первый вброс 2026-11-06

## Где показываются

На всех экранах, **кроме**:

- Экрана приветствия (см. [01-welcome.md](01-welcome.md))
- Экрана первого заполнения профиля (см. [01-welcome.md](01-welcome.md))
- ❓ Экрана ожидания одобрения (не описан; вероятно, тоже без шапки)

## Шапка (верхняя полоса на всю ширину)

Элементы слева направо:

| Элемент | Расположение | Вид и поведение |
|---|---|---|
| Герб гильдии + название гильдии | левый угол | ✅ Логоблок; клик → **ДАШБОРД** (решено [В], 2026-11-06) |
| Игровое время | центр | ✅ Иконка текущей фазы (день/ночь) + сколько осталось до смены фазы. Расчёт — `getGamePhase` из `packages/shared`, якорь цикла день/ночь — настройка гильдии (см. AGENTS.md, правило 5). ❓ показывать ли точное время смены (tooltip/подпись) |
| Количество очков ДКП | правый угол | ✅ Баланс игрока (сумма записей журнала) — просто цифра, не кликабельна (решено [В], 2026-11-06) |
| Аватар игрока | правый угол | ✅ «Условный» аватар. ❓ источник картинки: Discord-аватар или генерируемый |
| Ник игрока | правый угол | ✅ Клик по нику или аватару → **ПРОФИЛЬ ПЕРСОНАЖА** |
| Роль на сайте | правый угол | ✅ Отображается рядом с ником. ❓ формат (текст/значок), какие значения ролей |
| Кнопка «Выход» | правый угол | ✅ С подтверждением; после выхода — экран приветствия (решено [В], 2026-11-06) |

## Боковая шторка (навигация по разделам)

- Расположена в левой части экрана.
- ✅ **Свёрнута по умолчанию**: видны только иконки пунктов.
- ✅ В верхней части шторки — кнопка разворачивания (иконка «три
  горизонтальные линии»).
- ✅ Вертикальный список разделов; клик по пункту — переход на страницу.

| Пункт | Кому виден | Цель перехода |
|---|---|---|
| ДАШБОРД | ✅ все | [02-dashboard.md](02-dashboard.md) |
| РАСПИСАНИЕ | ❓ | [03-schedule.md](03-schedule.md) |
| СОСТАВ ГИЛЬДИИ | ❓ | [04-roster.md](04-roster.md) |
| АУКЦИОН | ❓ | ⏸ описание к этапу 2 |
| ЛОГ ДЕЙСТВИЙ | ✅ все авторизованные | [05-audit-log.md](05-audit-log.md) |
| НАСТРОЙКИ | ✅ только Глава и Админ | [06-settings.md](06-settings.md) |

- ✅ Пункты, недоступные по правам, **скрываются целиком** (не блокируются)
  (решено [В], 2026-11-06).
- ✅ Мобильная версия: шторка выдвигается **поверх хедера** — удобно
  пользоваться только ей (решено [В], 2026-11-06).
