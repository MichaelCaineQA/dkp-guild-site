# Статистика

Статус: согласовано владельцем, 2026-11-08; целевой экран этапа 4,
не отметка о готовности реализации.

Требования и расчёты: [PLAN.md, раздел 2.8](../PLAN.md#28-статистика-и-дашборды).
Этот документ описывает их представление в интерфейсе.

## Роут и доступ

- Целевой роут `/statistics`, пункт «Статистика» в общей навигации.
- Доступ: одобренные авторизованные участники всех рангов и Админ.
  Лидерство КП/пака и назначение РЛ не ограничивают общую статистику
  своей командой и не открывают дополнительные данные GS.
- Шапка и шторка — [00-common.md](00-common.md); активный пункт подсвечен.
- Блок свежести GS доступен только Главе/Админу. Для остальных он скрыт,
  защищённые значения не передаются через API и CSV. Права на подробности
  и связанные экраны проверяются независимо от права видеть сводку.

## Макет

1. Заголовок «Статистика», подпись «Посещаемость, активность, ДКП и лут».
2. Общая панель периода и фильтров, действующая на все вкладки.
3. Четыре сводные карточки.
4. Вкладки «Обзор», «Посещаемость», «Активность», «ДКП», «Лут».
5. Содержимое выбранной вкладки.

На компьютере карточки стоят в ряд, графики и таблицы — в сетке по ширине
контента. Референс задаёт расположение блоков, а цвета, шрифты, навигация
и компоненты берутся из текущего сайта Sun Eclipse. Декоративные фоновые
изображения не должны ухудшать читаемость.

## Элементы

### Общая панель

- Период: по умолчанию текущий календарный месяц; выбор другого месяца
  или произвольных дат «С» / «По». Сезонов нет.
- Рядом с датами подпись «По Москве, UTC+3». Конечная дата включена:
  технически интервал от полуночи первого дня до полуночи следующего
  после последнего дня, без включения правой границы.
- Фильтры: КП, пак, тип ивента, PvE/PvP. Каждый необязателен, условия
  работают совместно через И. Варианты паков согласованы с выбранной КП;
  несовместимый выбор сбрасывается с видимым обновлением фильтра.
- «Сбросить» возвращает текущий месяц и снимает остальные фильтры.
- Выбранные условия сохраняются при переходе между вкладками;
  заголовки таблиц и CSV содержат период и применённые фильтры.
- Все отчётные виджеты используют один период. Недели пн–вс на графиках
  обрезаются его границами; неполные недели подписываются фактическими датами.
- Ивент попадает в период по дате начала; финансовая операция — по дате
  записи в журнале. Поздняя корректировка попадает в финансовый отчёт
  даты корректировки; в деталях виден связанный исторический ивент.
- Исторические подписи и фильтрация команд используют принадлежность
  на момент ивента. Игрок без пака показан как «Без пака».

### Сводные карточки

| Карточка | Значение | Переход |
|---|---|---|
| Активные участники | Число разных игроков хотя бы с одной принятой стартовой/финальной отметкой в выборке завершённых ивентов | «Активность», таблица игроков |
| Завершено ивентов | Число разных завершённых ивентов выбранного периода и фильтров | «Активность», таблица ивентов |
| Посещаемость | Общая посещаемость выборки по формуле плана; рядом число отметок и учитываемых участий | «Посещаемость» |
| Начислено ДКП | Сумма начислений за чек-ин и ручных начислений за период; без трат и корректировок | «ДКП», начисления |

«Активные участники» — число, без неподтверждённого знаменателя вроде
68/70. При нескольких игроках одного ивента сам ивент считается один раз.

### Обзор

- График посещаемости по неделям: процент и исходные числа в подсказке.
- График количества завершённых ивентов по неделям. Сумма столбцов
  совпадает с карточкой «Завершено ивентов» при тех же условиях.
- «Топ по посещаемости»: первые пять игроков, аватар, ник, процент,
  отметки / максимум отметок и число учитываемых ивентов.
  Игроки без учитываемых ивентов не участвуют в рейтинге.
  Сортировка: процент по убыванию, затем число учитываемых ивентов
  по убыванию, затем ник; значения сравниваются до округления.
  Малый объём участия виден рядом с процентом, поэтому 100% за один
  ивент не выглядит равнозначным 100% за двадцать.
- Таблица активности по типам ивентов: тип, завершено ивентов,
  участники, посещаемость. Вместо таблицы успешности боссов.
- «Чаще всего выпадает»: предмет, количество, доля от всех выпадений,
  строка «Остальное» и переход во вкладку «Лут».
- Главе/Админу дополнительно блок свежести GS: количество актуальных,
  устаревших и отсутствующих скриншотов, доля устаревших, дата среза.
  Порог устаревания — из существующего правила профиля, не новый порог
  экрана статистики. Исторический срез использует записи и состав
  на конец периода; текущий месяц — на момент формирования отчёта.

Успешность/поражения рейдов и время убийства боссов не отображаются
и не требуют ввода новых данных при проведении ивента.

### Посещаемость

- Переключение разреза «Игроки / Паки / КП / Гильдия».
- Таблица: игрок или команда, учитываемые ивенты/участия, принятые отметки,
  посещаемость, уважительные отсутствия, неявки, опоздания, ранние уходы.
  Для команды «участия» — пары игрок–ивент, а не число уникальных ивентов.
- График динамики по неделям, переход к перечню ивентов и отметок,
  из которых получена выбранная строка.
- Пояснение формулы доступно по нажатию и с клавиатуры:
  `посещаемость = (число принятых отметок / 2) / число учитываемых ивентов × 100%`.
  Уважительные отсутствия исключаются из расчёта; пропуски без причины
  остаются в знаменателе. Только завершённые ивенты, на которые игрок
  был приглашён в соответствующем составе. Ручная стартовая/финальная
  отметка равнозначна принятому коду, не добавляет третью отметку.
- Пример: 10 завершённых приглашённых ивентов, из них 2 уважительных
  отсутствия; 12 отметок из 16 возможных дают `(12 / 2) / 8 × 100% = 75%`.
  Ноль отметок при положительном знаменателе — 0%; ноль учитываемых
  ивентов — «—» и пояснение «Нет ивентов для расчёта».
- Командный процент рассчитывается по суммарным отметкам и участиям,
  не усреднением процентов игроков. Для отображения округляем до одного
  десятичного знака; в деталях доступны исходные числа.
- Источник уважительного отсутствия — итоговое уважительное отсутствие
  для пары игрок–ивент. Заявка, которую отменили, не исключает участие;
  наличие заявки само по себе не обнуляет фактические отметки игрока.

### Активность

- Распределение участия по типам ивентов и PvE/PvP.
- Динамика по неделям и пик активности по дням недели/времени Москвы;
  период и временная шкала подписаны явно.
- Таблица игроков: ник, команда на момент ивента в деталях,
  число посещённых ивентов, принятые отметки, распределение по типам.
  При смене команды детали разделяют соответствующие участия.
- Таблица ивентов: дата, название, тип, режим, область приглашения,
  число участвовавших и приглашённых, посещаемость. Название открывает
  [карточку ивента](08-event-card.md).
- Участие хотя бы с одной отметкой учитывается один раз в числе
  посещённых ивентов; процент посещаемости продолжает учитывать половины.

### ДКП

- Раздельные показатели и динамика: начислено, потрачено на аукционах,
  корректировки со знаком. Не называть сумму положительных записей
  всех типов «заработком»: положительная корректировка остаётся корректировкой.
- Таблица игроков/паков/КП с теми же показателями; раскрытие суммы
  показывает операции журнала с типом, датой, суммой и связанным ивентом/лотом.
- Балансы на конец периода явно подписаны «Баланс на …»; для текущего
  месяца — время формирования отчёта. Начисления и траты считаются
  за период, баланс — накопительно к указанному моменту.
- При выборе типа ивента/PvE–PvP начисления и траты фильтруются по
  связанному ивенту. Самостоятельные операции показаны отдельной
  категорией «Без ивента», не приписываются выбранному типу или режиму
  и не подмешиваются в его итог. Категория явно отделена от результатов
  фильтра, её операции раскрываются отдельно.
- Полный баланс выбранных игроков на конец периода остаётся полным:
  рядом подпись «Без учёта фильтра типа ивента» (при выбранном режиме —
  также PvE/PvP). Нельзя выдавать сумму отфильтрованных операций за
  полный баланс счёта. Подпись и это исключение сохраняются в CSV.

### Лут

- Внутреннее переключение «Выпало / Получено».
- «Выпало»: предмет с иконкой, количество выпадений, доля от общего
  количества; детали по ивентам. В топе знаменатель включает и предметы
  за пределами показанных строк, остаток объединяется в «Остальное».
- «Получено»: получатель, предмет, ивент/лот, дата получения,
  фактическая цена в ДКП с применённой наценкой. Группировка по игрокам,
  пакам и КП показывает число предметов и сумму фактических цен.
- Выпавший, но ещё не распределённый предмет попадает в «Выпало»,
  но не в «Получено»; выпадение не означает состоявшуюся покупку.
- Период выпадений относится к факту выпадения, получения — к факту
  получения. Поэтому итог двух представлений не обязан совпадать.
  Историческая команда определяется по связанному ивенту.
- Переход к игроку, ивенту или лоту — при наличии доступа к цели.

## Действия

- Смена периода или фильтра обновляет карточки, графики, рейтинг,
  таблицы и экспорт выбранной вкладки; старые данные нельзя показывать
  под уже изменёнными подписями без состояния обновления.
- Клик по карточке/элементу графика раскрывает соответствующую таблицу
  с сохранёнными общими условиями; дополнительный выбранный срез виден
  отдельным условием, которое можно снять.
- «Скачать CSV» у каждой таблицы: вся отфильтрованная выборка,
  не только текущая страница; русские заголовки, период и часовой пояс.
  Поля GS исключаются по тем же правам, что в интерфейсе и API.
- Графики имеют подписи, легенду и значения; цвет — дополнительное,
  а не единственное средство различать категории. Подсказки доступны
  по нажатию, наведению и фокусу клавиатуры.

## Состояния

- **Пустой период:** числовые количества и суммы — 0, процент без
  знаменателя — «—». Графики и таблицы показывают «Нет данных за выбранный
  период»; рейтинг не заполняется вымышленными игроками.
- **Нет совпадений:** «По выбранным фильтрам ничего не найдено», действие
  «Сбросить фильтры». Отличать от отсутствия данных вообще.
- **Загрузка:** каркас карточек и графиков; при смене фильтров видимое
  состояние обновления. Ответ старого запроса не заменяет новый отчёт.
- **Ошибка:** сообщение и «Повторить» с сохранением периода и фильтров;
  ошибку запроса нельзя подменять нулевыми значениями.
- **Нет прав:** неавторизованный пользователь проходит вход; ожидающий
  одобрения остаётся на соответствующем экране. Блоки GS скрыты у тех,
  кому они недоступны, в том числе при прямом запросе и экспорте.
- **Недостаточная история:** при отсутствии исторического состава или
  GS — явная пометка «Нет исторических данных». Текущий состав нельзя
  незаметно подставлять вместо прошлого.
- **Мобайл:** одна колонка карточек и графиков, фильтры переносятся
  на строки, вкладки прокручиваются горизонтально. Широкая таблица
  прокручивается внутри своего блока, не расширяя всю страницу.
