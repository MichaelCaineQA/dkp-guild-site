# Лог действий

Статус: вопросы ревизии согласованы (2026-11-06) · Источник: [В] шестой вброс 2026-11-06

## Роут и доступ

- Пункт «Лог действий» боковой шторки (см. [00-common.md](00-common.md)).
- ✅ Полный журнал доступен только **Офицеру, Главе и Админу**
  (решено [В], ревизия, ответ 27; соответствует PLAN.md 2.9).
  Для остальных пункт меню и кнопка перехода в полный лог скрыты;
  ограничение действует и на API. Последние 10 записей для пользователей
  с доступом — в виджете дашборда, см. [02-dashboard.md](02-dashboard.md).

## Содержимое

- ✅ Список **всех действий** с:
  - изменениями **ДКП**;
  - составом **КП и Паков**;
  - **лотами на аукционе**;
  - **событиями**.
- ✅ Оформление — список (лента записей).
- ✅ Сортировка: **всегда от новых к старым** (не переключается).

## Пагинация и фильтры

- ✅ Пагинация с выбором размера страницы: **10 / 50 / 100** записей.
- ✅ Фильтр по **типу сущности** — **плоский список**: ДКП / КП / Пак /
  лот / событие (решено [В], 2026-11-06).
- ✅ Фильтр по **пользователю, совершившему действие** (+ **системные**
  действия, автор — «Система»).
- ✅ Фильтр **по дате** (диапазон; решено [В], 2026-11-06). Счётчика всего
  записей **нет** (решено [В], 2026-11-06).

- ✅ Каждый фильтр **необязателен**: можно выбрать один, любую пару или все
  три. Выбранные условия действуют **совместно (И)**: запись должна
  соответствовать каждому активному фильтру. Неуказанный фильтр не
  ограничивает выборку (решено [В], ревизия, ответ 28).

## Прочие решения

Решено (2026-11-06):

- Поля записи — **кто / что / над чем / когда**, без кликабельных ссылок из
  записей.
- **Системные действия** («сделай как правильно», делегировано [В]):
  автор — **«Система»** (псевдо-пользователь), примеры: авто-EXCUSED при
  закрытии события, автоматические начисления по итогам. В фильтре по
  пользователю — отдельная опция «Система».
- Чек-ин коды: в логе только факт «код сгенерирован», сами коды не пишутся
  никогда.
- Фильтр типов — плоский список; есть фильтр по дате; счётчика всего нет.

## Заметки для реализации

- Источник данных — `AuditLog` (правило 4 AGENTS.md: любое ручное действие
  пишет запись). Доступ к полному журналу проверяется на уровне API;
  публичные журналы ДКП/лута не открывают доступ к полному аудиту.
- Для Офицера/Главы/Админа виджет дашборда показывает срез из того же
  источника — 10 последних записей.
- Изменения своего профиля также журналируются (ревизия, ответ 33).
  Доступ к полному аудиту не расширяет видимость GS/скриншотов: комментарии,
  значения полей и ссылки в записи должны учитывать ограничения из
  [07-profile.md](07-profile.md), чтобы не раскрывать скрытые данные.
