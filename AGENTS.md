# AGENTS.md — правила проекта для людей и ИИ-ассистентов

ДКП-система гильдии в Throne and Liberty. **Сначала прочитай
[docs/PLAN.md](docs/PLAN.md)** — единственный источник требований, игровых
механик и решений гильдии. Если код или другие документы противоречат плану,
правильнее план. Не меняй план и игровые правила без явной просьбы владельца.
Не заводи отдельные спеки, OpenSpec или RFC; задачи и статус фич — в GitHub Issues,
milestone = этап плана.

## Тематическая память

Перед изменениями прочитай обязательные инструкции:

- [Архитектура и ограничения](docs/agent-memory/architecture.md) — карта кода,
  ДКП-журнал, настройки, аудит, время, права и язык UI.
- [Разработка и проверки](docs/agent-memory/workflow.md) — команды, миграции,
  зависимости, PR и экономное делегирование.

По теме задачи открывай:

- [Навигация по ключевым решениям](docs/agent-memory/decisions.md) — указатель
  разделов плана и справочников без отдельной копии требований.
- [Известные проблемы и ловушки](docs/agent-memory/known-issues.md) — расхождения
  документации и диагностика типовых проблем окружения.

Эти файлы — рабочая память, не новая спецификация и не трекер реализации.
Обновляй их при изменении соответствующих фактов; у записей о проблемах указывай
источник, дату проверки и способ повторной проверки. Не записывай предположения
как подтверждённые баги, не сохраняй секреты. Завершённую задачу отмечай в Issue,
а в памяти оставляй только полезный для следующих задач контекст.

Другие справочники: [README.md](README.md) — запуск и эксплуатация;
[CONTRIBUTING.md](CONTRIBUTING.md) — процесс работы;
[docs/ui/](docs/ui/README.md) — представление экранов, не требования;
[apps/web/DESIGN.md](apps/web/DESIGN.md) — устройство визуальных компонентов.
